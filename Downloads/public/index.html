Cross-compilation *OS bootstrap

Procursus

A build system that provides a large set of consistently up-to-date *nix tools, cross-compiled to work on Darwin-based platforms: iOS, iPadOS, tvOS, watchOS and macOS.

Get Procursus apt.procurs.us

Why Procursus

/01

Makefile-driven

Packages build in parallel and new ones are easy to add, so it doesn't fall behind upstream.

/02

Jailbreak-agnostic

It ships no hooking platforms or code-injection packages. Any project can use it as a plug-and-play base.

/03

Every package manager

It was the first bootstrap to work out of the box with all four main package managers, including Sileo and Zebra.

/04

Open source

Built on GNU tools and open to community contributions.

Install on a device

  1. Use a Procursus-based jailbreak

    Most modern jailbreaks, and macOS setups that use Procursus, install the bootstrap for you. If yours does, the Procursus repo is already configured.

  2. Add the repository

    If you need to add it by hand, add this source in Sileo, Zebra, Cydia or Installer:

    https://apt.procurs.us/

  3. Install packages with APT

    From a terminal on the device:

    sudo apt update
sudo apt install <package>

Procursus targets jailbroken Darwin devices and supported macOS setups. Check that your jailbreak supports Procursus before you install anything, because mixing bootstraps can break a device.

Build from source

  1. Clone the repo

    git clone https://github.com/ProcursusTeam/Procursus.git
cd Procursus

  2. Install the build dependencies

    You need a Darwin SDK and toolchain, plus GNU make, coreutils and the other tools listed in the wiki.

  3. Build

    # build a single package
make <package>-package

# build the full bootstrap
make bootstrap
